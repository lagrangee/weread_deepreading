# v1.2.0：深读下载入口与稳定性更新

## 范围与决定

- 阅读面板提供同一作者的深读 iPhone App 入口，可展开本地二维码，可永久隐藏。
- 设置页「关于」、GitHub README 和商店描述提供直达 App Store 的链接；不增加中间页面。
- 深读 App Store ID：6827442865；需要 iOS 17 及以上、自备 AI Key，讨论不与插件同步。
- 保留 API Key、模型配置与偏好随 Chrome 账号同步，不迁移、不删除已有同步数据。
- 不新增模型服务商或 host_permissions，不更换已有用户配置的模型，不采集推广追踪事件。

## 本轮修复

- SSE 允许 data 后无空格、多行事件、跨分片中文、无换行尾帧，错误事件显示失败。
- 断线与取消请求正确收尾，保留已有回答和追问上下文，忽略迟到回调。
- Markdown 使用 DOMPurify 白名单清洗，禁止自动加载图片、危险链接、脚本与事件属性。
- 中文输入法确认不发送，Enter 发送，Shift+Enter 换行，保留浏览器组合键与其他编辑区域行为。
- 关闭面板保存的 false 不再被默认 true 覆盖。
- 删除输入密钥、回答、选文与书名的调试日志；据实更新 Chrome 同步说明。
- 补齐 Jest 环境与变换，发布检查包含二维码资源。

## 验证

- Jest：5 套、37 项回归测试通过；流式、渲染与 false 状态问题均有修复前失败证据。
- 变更源码与新增测试 ESLint 通过；全项目 lint 仍有旧版拖拽/缩放、桥接工具和第三方库中的既存问题，本轮未批量重排。
- 生产构建、打包和发布前检查通过，ZIP 内文件与 dist 一致，包含依赖许可证和二维码。
- 隔离 Chromium 加载真实 unpacked 扩展，使用模拟书页与模拟模型响应验证 12 项界面/交互场景，未调用真实收费模型、未读取私人浏览器配置。
- 浏览器覆盖：1440×900、设置页 800×900，包含明暗主题、展开二维码、隐藏后刷新、输入法/换行、回答清洗、中断恢复和关闭后刷新。
- 未验证 Chrome 88 实机、真实服务商收费请求、手机相机实际扫码安装；不以模拟服务验证替代上述范围。
